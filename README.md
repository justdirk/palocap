# Palocap — sito

Sito statico per **Palocap**, abbigliamento personalizzato a Milano dal 1998.
Ricamo, stampa e dipinto a mano. Corso di Porta Ticinese 1 e Piazza Piemonte 10.

## Struttura

Un solo file, `index.html`, senza dipendenze di build.
Tutte le immagini sono incorporate come data URI, quindi la pagina funziona
anche aperta in locale con un doppio clic. Gli unici file esterni sono i font
(Google Fonts: Bodoni Moda e Archivo).

## Pubblicazione

GitHub Pages, da `main` / root.
Impostazioni → Pages → Source: Deploy from a branch → Branch: `main`, cartella `/ (root)`.
